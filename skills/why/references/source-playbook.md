# Source playbooks

The why skill spawns one investigator per available evidence category, each reading a single source-specific playbook below. The playbooks are written for the tools Curtis's team uses.

| Category | Playbook | Tool |
|---|---|---|
| Source control history | [`code-archaeology.md`](./sources/code-archaeology.md) | git, `gh` |
| Issue / ticket tracker | [`linear.md`](./sources/linear.md) | Linear MCP |
| Product planning | [`asana.md`](./sources/asana.md) | Asana MCP |
| Meeting notes | [`granola.md`](./sources/granola.md) | Granola MCP |
| Real-time team chat | [`slack.md`](./sources/slack.md) | Slack MCP |
| Infrastructure | [`aws.md`](./sources/aws.md) | `aws` CLI |
| Product analytics | [`posthog.md`](./sources/posthog.md) | PostHog MCP |
